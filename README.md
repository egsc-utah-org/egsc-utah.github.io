# egsc-utah.github.io

Static public website for the Engineering Graduate Student Council at the University of Utah.

## Files

- `index.html` contains the single-page public site.
- `styles.css` contains the responsive layout and visual system.
- `script.js` powers the mobile navigation.
- `assets/constitution.pdf` is the attached constitution used as source material.
- `assets/egsc-logo-horizontal.png` is the official horizontal EGSC logo asset.

## Local preview

Run a static server from the repository root:

```bash
python3 -m http.server 8000
```
